# Brand

The Teltonika icons and logos in this folder are the ones published for the core
Teltonika integration in the [home-assistant/brands](https://github.com/home-assistant/brands)
repository (`core_integrations/teltonika`). The same files ship with the integration in
`custom_components/teltonika_ntp/brand/` so Home Assistant and HACS show the Teltonika icon.

Teltonika.
